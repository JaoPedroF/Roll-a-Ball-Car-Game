# Roll-a-Ball-Car-Game

Jogo criado como primeiro projeto da disciplina "Programação de Jogos"
Orientador: Murilo Boratto
Discentes: João Ferreira, Gabriel Nascimento

Jogo produzido através da Unity, publicado no Play Unity
Versão: Unity 6 (6000.0.82f1)

Link do jogo: https://play.unity.com/en/games/3be17524-34a6-4a84-b854-68808b8c1a14/roll-a-ball-atividade-3d-pj

Código feito pelo Microsoft Studio Code
Música feita pelo FL Studio 21
Modelagem 3D do Carro feita pelo Blockbench

# Controles:

W/A/S/D e/ou Setas do teclado - Movimentação

Espaço - Frear
